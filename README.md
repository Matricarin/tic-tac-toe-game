# Игра Крестики-нолики

Консольная игра на C# / .NET 8: человек (X) против компьютера (O, minimax).
Размер доски: 3×3, 5×5 или 10×10. Кто ходит первым, выбирается случайно.

## Запуск

```bash
dotnet run --project TicTacToe
dotnet test
```

Ход: номер клетки (нумерация слева направо, сверху вниз) или два числа `строка столбец` (с 1).
После партии: `д` / `y` — сыграть ещё.

На доске 5×5 и 10×10 компьютер ищет на ограниченной глубине (полный перебор слишком большой).
Выигрыш — полностью заполненный ряд, столбец или одна из двух главных диагоналей.

## Приёмы Cursor, которые уже были в этом проекте

1. **Plan mode** — сначала согласовали архитектуру, потом агент писал код.
2. **Agent mode** — создание файлов, правка тестов, запуск `dotnet` из чата.
3. **Итерации** — следующее сообщение может быть точечным: «добавь уровень Easy» или «исправь этот тест» с `@TicTacToe.Tests`.
4. **Git** — коммит только если вы явно попросите.
5. **Rules** — в `.cursor/rules` можно зафиксировать конвенции (русский UI, net8, не коммитить без запроса).

Попробуйте следующим сообщением, например: «сделай сложность Easy: случайный ход» или «добавь счёт по партиям».
